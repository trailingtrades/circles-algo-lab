# Apply the 19 Sep 2026 nginx changes — learn.optionlab.co.in

In short (Hinglish): PR merge aur deploy green hone ke baad, Git Bash mein neeche ke blocks ek-ek karke
chalaiye. Step 3 khud backup leta hai, `nginx -t` fail ho to khud purani setting wapas laga deta hai.

**When:** after the PR is merged and `deploy-smart-vps.yml` is green (section F of the go-live order in
`docs/5C_LEARN_GOLIVE_CHECKLIST.md`). **Who:** Rahul, or Claude from Rahul's machine — the VPS firewall
only accepts SSH from Rahul's IPs. **Time:** about 5 minutes. **Downtime:** none (`systemctl reload`
is graceful).

## What changes

| Path | Before | After |
|---|---|---|
| `/winners/about/`, `/one/about/` | 302 to the SMART sign-in | 200, public (they are the Stage 2/3 sales pages) |
| `/smart/about`, `/winners/about`, `/one/about` (no slash) | app redirect / sign-in | 301 to the slash version |
| `/`, the three about pages, `/winners/`, `/one/`, `/fonts/` | nosniff, X-Frame-Options, Referrer-Policy | the same plus HSTS, Permissions-Policy and a CSP |
| `/admin.html` (Mentor Desk) | 200 to anyone | 404 to everyone; step 5 opens it for your IP |
| any missing static path | nginx's default "404 Not Found" | branded `/404.html` with the SEBI line and Tier-1 disclaimer |
| `/smart` app | client could set X-Forwarded-For; `X-Powered-By: Next.js` | X-Real-IP / X-Forwarded-For = the real address; header removed |
| POSTs to `/smart/learn`, `/smart/learn/invite/…`, `/smart/learn/reset…` | unlimited | 10 a minute per address, burst 10, then 429 (plain text `rate_limited`; the form says "Too many attempts") |
| signed-in student without a stage grant opening `/winners/` or `/one/` (gate ON only) | 302 to `/smart/learn/home` | 302 to `/smart/learn/home?stage_denied=<no_access\|not_started\|expired>`; Home explains it |
| `/404.html` in the webroot | — | installed only when the Academy deploy has not already put its own there (the Academy build owns it) |
| `/learn?error=link` (Vercel-era link) | query string dropped | kept: 301 to `/smart/learn?error=link` |

`location = /` and `location = /admin.html` move out of the server block into
`snippets/academy-site.conf`; `apply-nginx.sh` comments the old copies out (it does not delete them).

## 0. Open Git Bash in the repo

Run once per Git Bash window; later steps use `ssh_` and `H`.

```bash
cd /c/dev/circles-algo-lab
git fetch -q origin main && git log -1 --format='%h %ad %s' --date=short origin/main -- apps/learn/deploy-vps
KEY=~/.ssh/optionlab_vps; HOST=root@200.141.9.107; H=https://learn.optionlab.co.in
ssh_() { ssh -i "$KEY" -o StrictHostKeyChecking=accept-new "$HOST" "$@"; }
ssh_ 'hostname; nginx -v'
```

Expect: the log line is this PR's merge commit (dated 19 Sep or later), then the host name and
`nginx version: nginx/1.x`. If the log line is older, the PR is not merged yet — stop.

## 5. Open the Mentor Desk for your IP (only if you still use /admin.html)

```bash
MYIP=$(ssh_ 'echo ${SSH_CLIENT%% *}'); echo "the VPS sees you as: $MYIP"
ssh_ "sed -i -E 's/^([[:space:]]*)(# )?allow [^;]+;/\1allow $MYIP;/' /etc/nginx/snippets/academy-site.conf && nginx -t && systemctl reload nginx"
```

Expect `200` from this machine; everyone else still gets `404`. When your internet address changes
(new router session, hotspot), run the block again. Re-running `apply-nginx.sh` closes the desk again.

different address (often IPv6) — tell Claude.

```bash

```

## Rollback

Everything from step 3 in one go — use the folder step 3 printed:

```bash
ssh_ 'ls -1d /root/nginx-backup-*'
ssh_ 'bash /root/nginx-backup-YYYYMMDD-HHMMSS/rollback.sh'
```

Expect `rolled back; nginx reloaded`. Each run of `apply-nginx.sh` makes its own backup, so the oldest
folder from the day is the state before any of it. Newest backup, without typing the name:

```bash
ssh_ 'bash "$(ls -1d /root/nginx-backup-* | tail -1)/rollback.sh"'
```

Smaller undos without a full rollback:

```bash
# A whole class signing in from one Wi-Fi sees 429: allow a bigger burst
# (the app has its own per-address limit too: raise IP_PER_MIN in src/lib/auth/rateLimit.ts and deploy)
ssh_ "sed -i 's/burst=10 nodelay/burst=40 nodelay/' /etc/nginx/snippets/smart-app.conf && nginx -t && systemctl reload nginx"
```
